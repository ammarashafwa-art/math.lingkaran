Lingkaran Pusat O(0,0)

x² + y² = r²

Lingkaran dengan pusat di titik asal O(0,0) dan jari-jari r.

Contoh: r = 5 → x² + y² = 25
🎯

Lingkaran Pusat P(a,b)

(x−a)² + (y−b)² = r²

Lingkaran dengan pusat P(a,b) dan jari-jari r.

Contoh: P(3,2), r=4 → (x−3)²+(y−2)²=16
📐

Cara Menentukan Persamaan Lingkaran

1Diketahui pusat & r → langsung substitusi ke rumus
2Diketahui pusat & titik → r = √((x₂−x₁)²+(y₂−y₁)²)
3Menyinggung sumbu X → r = |b|
4Menyinggung sumbu Y → r = |a|
🧮

Contoh Soal Lengkap

Lingkaran pusat P(3,2) melalui titik A(7,5):

1r = √((7−3)²+(5−2)²) = √(16+9) = √25 = 5
2Persamaan: (x−3)² + (y−2)² = 25
(x−3)² + (y−2)² = 25
💡

Tips Cepat

📌
Singgung sumbu X

r = |koordinat y pusat|

📌
Singgung sumbu Y

r = |koordinat x pusat|

📌
Melalui titik asal O(0,0)

Persamaan: x² + y² = r²

📌
Pusat di sumbu X (b=0)

(x−a)² + y² = r²

📋

Bentuk Umum Persamaan Lingkaran

x² + y² + Ax + By + C = 0
Pusat P(−½A, −½B)  |  r = √((−½A)² + (−½B)² − C)
Contoh: x²+y²+4x−2y+1=0 → A=4, B=−2, C=1
Pusat=(−2,1), r=√(4+1−1)=√4=2
🔄

Melengkapkan Kuadrat Sempurna

1Kelompokkan suku x dan y
2Tambahkan (A/2)² dan (B/2)² ke kedua ruas
3Faktorkan → (x−a)²+(y−b)²=r²
💡

Latihan

1. x²+y²+4x−2y+1=0
2. x²+y²−6x+8y−24=0
1. Pusat(−2,1), r=2
2. A=−6,B=8,C=−24 → Pusat(3,−4), r=√(9+16+24)=7
📍

Posisi Titik terhadap Lingkaran

Substitusikan titik ke persamaan lingkaran:

🟢Di dalamx²+y² < r²
🔵Padax²+y² = r²
🔴Di luarx²+y² > r²
Contoh: A(2,7), r=8 → 4+49=53 < 64 → Di dalam
📏

Posisi Garis terhadap Lingkaran

Substitusi garis → kuadrat ax²+bx+c=0, hitung D=b²−4ac:

✂️MemotongD > 0
👆MenyinggungD = 0
🚫Tidak memotongD < 0
Contoh: y=3x+2 pada x²+y²+4x−y+1=0
→ 10x²+14x+3=0, D=76>0 → Memotong
💡

Posisi Titik — Pusat P(a,b)

Jika lingkaran berpusat di P(a,b), substitusi ke:

(x−a)² + (y−b)² ≶ r²
1Substitusi titik ke (x−a)²+(y−b)²
2Bandingkan hasilnya dengan r²
3< r² → dalam  |  = r² → pada  |  > r² → luar
Contoh: B(5,3), pusat P(3,2), r=5
(5−3)²+(3−2)²=4+1=5 < 25 → Di dalam
🔍

Posisi Titik — Bentuk Umum

Jika lingkaran bentuk umum: x²+y²+Ax+By+C=0, substitusi langsung:

f(x,y) = x² + y² + Ax + By + C
🟢Di dalamf(x,y) < 0
🔵Padaf(x,y) = 0
🔴Di luarf(x,y) > 0
Contoh: C(8,1) pada x²+y²+4x−8y−5=0
64+1+32−8−5 = 84 > 0 → Di luar
📐

Garis Singgung Persekutuan

🔵 GSPL (Persekutuan Luar)

d = √(JP² − (R−r)²)

JP=jarak pusat, R=jari besar, r=jari kecil

🟠 GSPD (Persekutuan Dalam)

d = √(JP² − (R+r)²)

JP=jarak pusat, R=jari besar, r=jari kecil

Contoh: R=5,r=3,JP=10 → GSPL=√96=4√6, GSPD=√36=6
🔢

Garis Singgung dari Titik Luar

d = √(JP² − r²)

d = panjang garis singgung dari titik luar ke titik singgung

Contoh: Titik P(6,0), lingkaran x²+y²=16
JP=6, r=4 → d=√(36−16)=√20=2√5
📌

Syarat Garis Singgung Lingkaran

Garis y=mx+c menyinggung x²+y²=r² jika:

c² = r²(1 + m²)
1Substitusi y=mx+c ke x²+y²=r²
2Sederhanakan jadi kuadrat dalam x
3Syarat singgung: D = 0
Contoh: y=2x+c menyinggung x²+y²=5
c²=5(1+4)=25 → c=±5
Garis singgung: y=2x+5 atau y=2x−5
🔗

Hubungan Dua Lingkaran

🔴
Bersinggungan dalam

JP = |R−r|, satu titik singgung, L kecil di dalam L besar

🟠
Bersinggungan luar

JP = R+r, satu titik singgung, keduanya di luar

🟡
Berpotongan

|R−r| < JP < R+r, dua titik potong

🟢
Kosentris

JP = 0, pusat sama, jari-jari beda

🔵
Saling lepas

JP > R+r, tidak ada perpotongan

🧮

Langkah Menentukan Hubungan

1Tentukan pusat & r masing-masing lingkaran
2Hitung JP = √((x₂−x₁)²+(y₂−y₁)²)
3Bandingkan JP dengan R+r dan |R−r|
Contoh: L1: pusat(0,0) r=3, L2: pusat(7,0) r=2
JP=7=3+2=R+r → Bersinggungan luar
📊

01Persamaan⭐ Mudah

Diketahui: Pusat O(0,0), r = 3
Rumus: x² + y² = r²
Substitusi: x² + y² = 3² = 9
Jawab: x² + y² = 9
02Persamaan⭐ Mudah
Tentukan persamaan lingkaran berpusat di O(0,0) dan melalui titik P(5, 12).
Hitung r: r = √(5²+12²) = √169 = 13
Persamaan: x² + y² = 169
Jawab: x² + y² = 169
03Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran dengan pusat P(1, 2) dan jari-jari r = 8.
Rumus: (x−a)²+(y−b)²=r²
Substitusi: (x−1)²+(y−2)²=64
Jawab: (x−1)² + (y−2)² = 64
04Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran pusat P(3, 2) yang melalui titik A(10, 2).
r: √((10−3)²+(2−2)²) = √49 = 7
Jawab: (x−3)² + (y−2)² = 49
05Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran pusat P(2, −9) yang menyinggung sumbu X.
Menyinggung sumbu X: r = |b| = |−9| = 9
Jawab: (x−2)² + (y+9)² = 81
06Bentuk Umum⭐⭐ Sedang
Tentukan pusat dan jari-jari dari x² + y² + 4x − 2y + 1 = 0.
A=4, B=−2, C=1
Pusat = (−2, 1)
r = √(4+1−1) = √4 = 2
Jawab: Pusat (−2, 1), r = 2
07Bentuk Umum⭐⭐ Sedang
Tentukan pusat dan jari-jari dari x² + y² − 6x + 8y − 24 = 0.
A=−6, B=8, C=−24
Pusat = (3, −4)
r = √(9+16+24) = √49 = 7
Jawab: Pusat (3, −4), r = 7
08Bentuk Umum⭐⭐⭐ Sulit
Tentukan jari-jari dari lingkaran yang berpusat di (3, −2) dan melalui titik (7, 1).
r = √((7−3)²+(1+2)²) = √(16+9) = √25 = 5
Jawab: r = 5
09Posisi Titik⭐ Mudah
Tentukan posisi titik A(2, 7) pada lingkaran dengan pusat O(0,0) dan jari-jari 8.
2²+7² = 4+49 = 53 < 64 = r²
Jawab: Titik A DI DALAM lingkaran
10Posisi Titik⭐⭐ Sedang
Tentukan posisi titik B(5, 3) pada lingkaran yang berpusat di P(3, 2) dan jari-jari 5.
(5−3)²+(3−2)² = 4+1 = 5 < 25 = r²
Jawab: Titik B DI DALAM lingkaran
11Posisi Titik⭐⭐⭐ Sulit
Tentukan posisi titik C(8, 1) pada lingkaran x² + y² + 4x − 8y − 5 = 0.
8²+1²+4(8)−8(1)−5 = 64+1+32−8−5 = 84 > 0
Jawab: Titik C DI LUAR lingkaran
12Posisi Garis⭐⭐⭐ Sulit
Tentukan posisi garis y = 3x + 2 pada lingkaran x² + y² + 4x − y + 1 = 0.
Substitusi → 10x²+13x+3=0
D = 13²−4(10)(3) = 169−120 = 49 > 0
Jawab: Garis MEMOTONG di dua titik
13Garis Singgung⭐⭐ Sedang
R=6, r=2, JP=10. Tentukan GSPL!
GSPL = √(100−16) = √84 = 2√21
Jawab: 2√21 ≈ 9,165
14Garis Singgung⭐⭐ Sedang
R=6, r=2, JP=10. Tentukan GSPD!
GSPD = √(100−64) = √36 = 6
Jawab: GSPD = 6
15Garis Singgung⭐⭐⭐ Sulit
Tentukan panjang garis singgung dari titik P(6, 0) ke lingkaran x² + y² = 16.
JP=6, r=4 → d = √(36−16) = √20 = 2√5
Jawab: 2√5 ≈ 4,472
16Hubungan⭐ Mudah
L1 pusat(0,0) r=3, L2 pusat(7,0) r=2. Tentukan hubungannya!

Jawab: SALING LEPAS
17Hubungan⭐⭐ Sedang

18Hubungan⭐⭐ Sedang

19Hubungan⭐⭐⭐ Sulit
L1 pusat(0,0) r=5, L2 pusat(4,0) r=2. Tentukan hubungannya!
JP=4, R+r=7, |R−r|=3 → |R−r| < JP < R+r
Jawab: BERPOTONGAN DI DUA TITIK
20Bentuk Umum⭐⭐⭐ Sulit

(x²−4x+4)+(y²+6y+9)=3+4+9
(x−2)²+(y+3)²=16
Jawab: Pusat (2,−3), r = 4
