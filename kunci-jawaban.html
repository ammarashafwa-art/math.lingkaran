📝 Kunci Jawaban — Soal Latihan

01Persamaan⭐ Mudah
Tentukan persamaan lingkaran berpusat di O(0,0) dan berjari-jari 3.
Diketahui: Pusat O(0,0), r = 3
Rumus: x² + y² = r²
Substitusi: x² + y² = 3² = 9
Jawab: x² + y² = 9
02Persamaan⭐ Mudah
Tentukan persamaan lingkaran berpusat di O(0,0) dan melalui titik P(5, 12).
Langkah 1 — Hitung r:
r = √(x² + y²) = √(5² + 12²) = √(25 + 144) = √169 = 13
Langkah 2 — Substitusi:
x² + y² = r² = 13² = 169
Jawab: x² + y² = 169
03Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran dengan pusat P(1, 2) dan jari-jari r = 8.
Diketahui: Pusat P(a,b) = (1,2), r = 8
Rumus: (x−a)² + (y−b)² = r²
Substitusi: (x−1)² + (y−2)² = 8² = 64
Jawab: (x−1)² + (y−2)² = 64
04Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran pusat P(3, 2) yang melalui titik A(10, 2).
Langkah 1 — Hitung r:
r = √((10−3)² + (2−2)²) = √(49 + 0) = √49 = 7
Langkah 2 — Persamaan:
(x−3)² + (y−2)² = 7² = 49
Jawab: (x−3)² + (y−2)² = 49
05Persamaan⭐⭐ Sedang
Tentukan persamaan lingkaran pusat P(2, −9) yang menyinggung sumbu X.
Aturan: Menyinggung sumbu X → r = |b| = nilai mutlak koordinat y pusat
r = |−9| = 9
Persamaan: (x−2)² + (y+9)² = 9² = 81
Jawab: (x−2)² + (y+9)² = 81
06Bentuk Umum⭐⭐ Sedang
Tentukan pusat dan jari-jari dari x² + y² + 4x − 2y + 1 = 0.
Identifikasi: A = 4, B = −2, C = 1
Pusat: P(−½A, −½B) = (−½·4, −½·(−2)) = (−2, 1)
Jari-jari:
r = √((−½A)² + (−½B)² − C) = √((−2)² + (1)² − 1) = √(4+1−1) = √4 = 2
Jawab: Pusat (−2, 1), r = 2
07Bentuk Umum⭐⭐ Sedang
Tentukan pusat dan jari-jari dari x² + y² − 6x + 8y − 24 = 0.
Identifikasi: A = −6, B = 8, C = −24
Pusat: P(−½·(−6), −½·8) = (3, −4)
Jari-jari:
r = √((3)² + (−4)² − (−24)) = √(9 + 16 + 24) = √49 = 7
Jawab: Pusat (3, −4), r = 7
08Bentuk Umum⭐⭐⭐ Sulit
Tentukan jari-jari dari lingkaran yang berpusat di (3, −2) dan melalui titik (7, 1).
Rumus jarak dua titik:
r = √((x₂−x₁)² + (y₂−y₁)²)
r = √((7−3)² + (1−(−2))²) = √(4² + 3²) = √(16+9) = √25 = 5
Persamaan: (x−3)² + (y+2)² = 25
Jawab: r = 5
09Posisi Titik⭐ Mudah
Tentukan posisi titik A(2, 7) pada lingkaran dengan pusat O(0,0) dan jari-jari 8.
Substitusi A(2,7) ke x²+y²:
2² + 7² = 4 + 49 = 53
Bandingkan dengan r²: r² = 8² = 64
53 < 64 → x²+y² < r²
Jawab: Titik A berada DI DALAM lingkaran
10Posisi Titik⭐⭐ Sedang
Tentukan posisi titik B(5, 3) pada lingkaran yang berpusat di P(3, 2) dan jari-jari 5.
Persamaan: (x−3)² + (y−2)² = 25
Substitusi B(5,3):
(5−3)² + (3−2)² = 4 + 1 = 5
5 < 25 = r²
Jawab: Titik B berada DI DALAM lingkaran
11Posisi Titik⭐⭐⭐ Sulit
Tentukan posisi titik C(8, 1) pada lingkaran x² + y² + 4x − 8y − 5 = 0.
Substitusi x=8, y=1:
8² + 1² + 4(8) − 8(1) − 5
= 64 + 1 + 32 − 8 − 5 = 84
84 > 0 → x²+y²+Ax+By+C > 0
Jawab: Titik C berada DI LUAR lingkaran
12Posisi Garis⭐⭐⭐ Sulit
Tentukan posisi garis y = 3x + 2 pada lingkaran x² + y² + 4x − y + 1 = 0.
Substitusi y = 3x+2:
x² + (3x+2)² + 4x − (3x+2) + 1 = 0
x² + 9x²+12x+4 + 4x − 3x−2 + 1 = 0
10x² + 13x + 3 = 0
Diskriminan: D = 13² − 4(10)(3) = 169 − 120 = 49
D = 49 > 0
Jawab: Garis MEMOTONG lingkaran di dua titik
13Garis Singgung⭐⭐ Sedang
Dua lingkaran dengan R = 6, r = 2, dan jarak pusat JP = 10. Tentukan panjang GSPL!
Rumus GSPL: d = √(JP² − (R−r)²)
d = √(10² − (6−2)²) = √(100 − 16) = √84 = 2√21
Jawab: GSPL = 2√21 ≈ 9,165
14Garis Singgung⭐⭐ Sedang
Dua lingkaran dengan R = 6, r = 2, dan jarak pusat JP = 10. Tentukan panjang GSPD!
Rumus GSPD: d = √(JP² − (R+r)²)
d = √(10² − (6+2)²) = √(100 − 64) = √36 = 6
Jawab: GSPD = 6
15Garis Singgung⭐⭐⭐ Sulit
Tentukan panjang garis singgung dari titik P(6, 0) ke lingkaran x² + y² = 16.
Lingkaran: x²+y²=16 → r=4, pusat O(0,0)
JP: √(6²+0²) = 6
Rumus: d = √(JP² − r²) = √(36−16) = √20 = 2√5
Jawab: d = 2√5 ≈ 4,472
16Hubungan⭐ Mudah
Dua lingkaran: L1 pusat(0,0) r=3, L2 pusat(7,0) r=2. Tentukan hubungannya!
JP = √((7−0)²+(0−0)²) = 7
R+r = 3+2 = 5  |  |R−r| = |3−2| = 1
JP = 7 > R+r = 5
Jawab: Kedua lingkaran SALING LEPAS
17Hubungan⭐⭐ Sedang
Dua lingkaran: L1 pusat(0,0) r=4, L2 pusat(6,0) r=2. Tentukan hubungannya!
JP = 6  |  R+r = 4+2 = 6
JP = R+r = 6
Jawab: BERSINGGUNGAN DI LUAR
18Hubungan⭐⭐ Sedang
Dua lingkaran: L1 pusat(0,0) r=5, L2 pusat(3,0) r=1. Tentukan hubungannya!
JP = 3  |  |R−r| = |5−1| = 4
JP = 3 < |R−r| = 4
Jawab: L2 berada DI DALAM L1 (tidak berpotongan)
19Hubungan⭐⭐⭐ Sulit
Dua lingkaran: L1 pusat(0,0) r=5, L2 pusat(4,0) r=2. Tentukan hubungannya!
JP = 4  |  R+r = 7  |  |R−r| = 3
|R−r| = 3 < JP = 4 < R+r = 7
Jawab: BERPOTONGAN DI DUA TITIK
20Bentuk Umum⭐⭐⭐ Sulit
Ubah x² + y² − 4x + 6y − 3 = 0 ke bentuk standar. Tentukan pusat dan jari-jarinya!
Kelompokkan: (x²−4x) + (y²+6y) = 3
Lengkapkan kuadrat:
(x²−4x+4) + (y²+6y+9) = 3+4+9
Faktorkan: (x−2)² + (y+3)² = 16
Pusat = (2, −3)  |  r = √16 = 4
Jawab: Pusat (2, −3), r = 4

r²=49 → r=√49=7

SOAL 6

A. (4,−6)

SOAL 7

A. Menyinggung
B. Tidak memotong

SOAL 8
Dua lingkaran kosentris artinya...
A. Jari-jarinya sama
B. Pusatnya sama ✓
C. Berpotongan dua titik
D. Saling lepas

SOAL 9

A. √(JP²+(R−r)²)
B. √(JP²−(R+r)²)
C. √(JP²−(R−r)²) ✓

GSPL = √(JP²−(R−r)²), GSPD = √(JP²−(R+r)²)
SOAL 10

B. (x−1)²+(y−2)²=9 ✓
C. (x−1)²+(y−2)²=3
D. x²+y²=9

SOAL 11
Jari-jari lingkaran x²+y²−6x+8y−24=0 adalah...
A. 5
B. 6
C. 7 ✓
D. 8
A=−6,B=8,C=−24 → r=√(9+16+24)=√49=7
SOAL 12
Titik B(5,3) pada lingkaran pusat P(3,2) r=5 berada...
A. Di luar
B. Pada lingkaran
C. Di dalam ✓
D. Tidak tentu
